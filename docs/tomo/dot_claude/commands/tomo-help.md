## WHY the /review Entry Says "Tomo's review section" (spec 046 T6.4, 0.2.25)

"A rerun replaces Tomo's section" could be read as covering the mapped sections too (the template headings the review
fills). A rerun replaces the "Tomo Review" section, and each mapped section gets only its own Tomo block replaced
(spec 046 F-sections: edits outside a block are kept). The line says so in one parenthesis.
