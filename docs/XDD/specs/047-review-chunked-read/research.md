- Link diffs over the whole period exclude periodic notes and attachments (review_period.py:263-286) — the "non-note embeds" parking-lot item is half done.
- Only size limit: `max_chars_per_day` 12000 (review_config.py:59), applied on a section boundary (review_day.py:261-275), sets `partly_read`. No per-file or per-week budget, no pagination. `--measure` prints `bytes` per file and `day_bytes` per month (review-read.py:200-209).

### 1.7 Complications with the brainstorm

- **C4** Digester weeks must come from `sources.rule`, not hard-coded ISO.
- **C5** Previous month (for a week) / previous quarter (for a month) may be kinds the user never set up → a fourth state beyond found/empty/missing.
- **C6** `from_previous_*` needs a third branch in `group_reason`/`check_item`, plus `_LABELS` en/de, schema enum, `Sources.of`. The Pass 2 suffix is plain text in the checkbox line.
- **C7** SKILL.md:11 and :238 name only `proposals.json` and `confirmed-<kind>.json`; moving `proposals.json` to an agent changes both and the pinned skill tests.
- **C8** Default session model sonnet; agents set their own model.
- **C9** `--measure` exists for the limit measurement.
- **C10** `test_review_privacy.py:212` allowlist needs the new files.

**Riskiest facts:** (1) one merged dict feeds all of review-doc; (2) delete-at-write (ADR-9) vs keeping digests for resume; (3) no read-side config for previous-note kinds.

## 2. Performance / capacity

- **Token ratio:** read JSON is ~1.85 chars/token, not 4 (717 KB / ~390k; month 190 KB / ~100k; 046 close-out :483). A 25k-token Read ≈ 46 KB.

- **KPIs now** (046 requirements.md:267, 349): week Pass 1 ≤ $0.80, month ≤ $2.00 / 7 min, Pass 2 ≤ $0.85, quarter ≤ $5.00 / 20 min. The brainstorm §2 still says week ≤ $0.50 (stale).
- **Day size:** ~5.8-5.9 KB/day compact (≈ 3.2k tokens), 7-day week ≈ 41 KB ≈ 22k tokens (tests/review_scaled_quarter.py:9-31). Pacer 0.3 s, doubles to `MAX_INTERVAL_S` 2.0, one end pass. Only `review-read.py` calls Kado → parallel agents add zero Kado load; previous notes go through the same pacer.
